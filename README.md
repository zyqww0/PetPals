# 📎 PetPals

## 📌 Project Overview

PetPals is a web platform that connects pet owners with trusted people who can temporarily host and take care of their pets when the owners are unable to do so.
The platform provides an easy way for pet owners to find suitable temporary hosts and communicate with them.

## 🎯 Project Objectives

- Provide an easy platform for pet owners to find temporary pet hosting.
- Connect pet owners with suitable hosts.
- Make the hosting process simple and organized.
- Provide a safe and convenient way to manage pet hosting requests.

📦 Project Scope
The project will include:

- User registration and login.
- Pet owner profiles.
- Pet information and profiles.
- Host profiles.
- Searching for available hosts.
- Sending and managing hosting requests.
- Managing bookings.
- Basic communication between users.
